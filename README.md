## 什么是 AS4837 线路，它和 9929、CN2 GIA 有什么区别

先把概念说清楚，后面看套餐才有判断依据。

AS4837 是中国联通 169 骨干网（AS9929 之外的普通联通网）的自治系统编号。在 VPS 圈子里说"4837 线路"，通常指**回程强制走联通 AS4837**——也就是服务器数据从美国回来的时候，统一借道联通 169 网回到国内三网。它和另外两条高端线的位置大致是这样：

- **CN2 GIA**：电信精品网，延迟最低、稳定性最好，价格也最贵，电信用户体感最好。
- **AS9929（CUII）**：联通 A 网精品线路，延迟低、稳定，属于联通的高端优化线，价格次之。
- **AS4837**：联通 169 普通网，负载相对低、丢包率较低，速度也不错，但延迟和稳定性比 9929 略逊，价格更便宜，**带宽通常给得更大**。

所以 4837 的定位很明确：**预算有限但又要保证三网回程优化的场景，或者对大带宽、大流量吞吐更敏感的场景**。如果你本地是联通宽带，4837 几乎是天然适合；电信和移动用户也能用，因为这类产品大多做的是"三网回程强制 4837"，不挑本地运营商。
